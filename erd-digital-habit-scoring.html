Keterangan Entitas & Alur Data

Input UserInput

Data yang dikirim pengguna via form web (POST /api/predict). Menjadi sumber utama seluruh pipeline.

  • gender: male / female
  • platform: Instagram, TikTok, X (Twitter), dll.
  • dailySocialMediaHours, sleepHours, stressLevel, physicalActivity

Derived SleepQualityMapping

Utilitas sleepMapper.js mengonversi jam tidur ke skor kualitas tidur (1–10) menggunakan aturan berbasis ambang batas.

  • Ideal 7–9 jam → skor 10
  • Penalti 1,5 poin/jam di bawah 7
  • Penalti 1,0 poin/jam di atas 9

Engine RawData

Representasi internal setelah normalisasi nama kolom. Dihasilkan oleh prediction.service.js sebelum masuk ke preprocessing.

Config PreprocessorConfig (JSON)

Tiga file JSON yang diekspor dari pipeline Python (scikit-learn). Menyimpan statistik StandardScaler dan kategori OneHotEncoder sehingga Node.js dapat mereplikasi preprocessing tanpa scikit-learn.

  • predict_happiness_config.json
  • predict_mental_health_config.json
  • predict_anxiety_config.json

Engine FeatureVector

Array numerik bertipe Float32Array yang dihasilkan preprocess.js: StandardScaler pada fitur numerik, OneHotEncoding pada fitur kategorikal, lalu diurutkan sesuai feature_names_out.

Model ONNXModel

Tiga model XGBoost Regressor yang dilatih di Python dan diekspor ke format ONNX. Dieksekusi di Node.js menggunakan onnxruntime-node secara paralel (Promise.all).

  • predict_happiness_model.onnx
  • predict_mental_health_model.onnx
  • predict_anxiety_model.onnx

Output PredictionResult

Tiga skor numerik hasil inferensi, masing-masing di-clamp ke rentang 1–10 oleh clamp.js.

  • happinessIndex: semakin tinggi semakin baik
  • mentalHealthScore: semakin tinggi semakin baik
  • anxietyScore: semakin tinggi = kecemasan makin tinggi

AI Prompt & IBMGraniteConfig

Prompt terstruktur dibangun oleh prompt.service.js dari RawData + PredictionResult, lalu dikirim ke IBM Granite API oleh watson.service.js menggunakan axios.

Output AIExplanation

Respons teks IBM Granite AI: Analisis (1 paragraf), Saran (3 poin aksi), dan Penutup (1 kalimat motivasi) — maks. 170 kata, Bahasa Indonesia.
